# `HTMShell`

The `HTMShell` module describes the local manifest and its portable layer-shell surfaces, including strict surface-local resources for typed component assignment. Package identity and local dependencies are documented by [`HTMShell.Package`](../HTMShell.Package/README.md).

## Types

- [`ShellManifest`](ShellManifest.md): Version 1 compatibility and version 2 package manifest.
- [`PanelSurface`](PanelSurface.md): Persistent top panel.
- [`OverlaySurface`](OverlaySurface.md): Output-local transient overlay.

See [create the first shell](../../guide/first-shell.md) for a complete package.
