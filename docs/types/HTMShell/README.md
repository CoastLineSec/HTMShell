# `HTMShell`

The `HTMShell` module describes the local manifest and its portable layer-shell surfaces.

## Types

- [`ShellManifest`](ShellManifest.md): Version 1 package manifest.
- [`PanelSurface`](PanelSurface.md): Persistent top panel.
- [`OverlaySurface`](OverlaySurface.md): Output-local transient overlay.

See [create the first shell](../../guide/first-shell.md) for a complete package.
