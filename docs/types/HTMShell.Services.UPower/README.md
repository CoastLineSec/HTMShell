# `HTMShell.Services.UPower`

The `HTMShell.Services.UPower` module provides process-scoped aggregate battery state.

## Types

- [`Battery`](Battery.md): Percentage, status, and warning state from UPower.

Battery state uses existing [`state-text`](../HTMShell.Elements/state-text.md) and [`state-token`](../HTMShell.Elements/state-token.md) elements.
