# `HTMShell.State`

The `HTMShell.State` module lists non-service state available to built-in bindings.

## State groups

- [`Output`](Output.md): Diagnostic output label and effective scale.
- [`Overlay`](Overlay.md): Output-local overlay status and activation count.
- [`Surface`](Surface.md): Surface template and presentation profile.
- [`Shell`](Shell.md): Output-local last action.

State keys are fixed typed names. Dotted names are not arbitrary object paths.
