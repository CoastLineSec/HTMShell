# Usage Guide

Start with the [introduction](introduction.md), then [run HTMShell from source](running-from-source.md).

The [first shell](first-shell.md) guide builds on the tracked static panel example. [Surfaces](surfaces.md) explains panels, overlays, outputs, and scaling. [State and actions](state-and-actions.md) covers the built-in HTML declarations. [Native state](native-state.md) introduces process state. [Clocks and dates](clock.md) covers semantic time elements. [Power state](power.md) covers UPower devices and power profiles. [PipeWire nodes](audio.md) covers read-only audio and media graph inspection.

Exact fields, values, and limitations are listed in the [type reference](../types/README.md).
