# Usage Guide

Start with the [introduction](introduction.md), then [run HTMShell from source](running-from-source.md).

The [first shell](first-shell.md) guide builds on the tracked static panel example. [Local packages](packages.md) covers package identity, schema version 2, local dependency graphs, and compatibility loading. [Components](components.md) covers inert manifest-owned templates, literal typed inputs, content slots, package-owned scoped stylesheets, declared raster resources, and explicit component use. [Surfaces](surfaces.md) explains panels, overlays, outputs, and scaling. [State and actions](state-and-actions.md) covers the built-in HTML declarations. [Native state](native-state.md) introduces process state. [Clocks and dates](clock.md) covers semantic time elements. [Power state](power.md) covers UPower devices and power profiles. [PipeWire audio](audio.md) covers node and routing inspection, volume, mute, channels, and typed controls. [Foreground filters](visual-effects.md) covers the complete bounded foreground-filter profile.

Exact fields, values, and limitations are listed in the [type reference](../types/README.md).
